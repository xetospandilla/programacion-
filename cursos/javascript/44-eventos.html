Lección 44: Eventos

La teoría está en los comentarios de 44-eventos.js; esta página es la práctica interativa. La sección 3 es la estrella: una lista de tareas funcional.

1. Eventos de ratón

Pasa el ratón por encima de este recuadro.

Resultado esperado: al entrar, el recuadro se resalta (clase resaltada); al salir, se quita. Se usan los eventos mouseenter y mouseleave.

2. Eventos de teclado

Aquí aparecerá la última tecla pulsada (evento keydown).

3. Formulario y validación: la lista de tareas

La tarea no puede estar vacía.

Resultado esperado: escribir una tarea y pulsar Enter o "Añadir" la inserta en la lista; una entrada vacía muestra el mensaje de error; cada tarea tiene botones para completarla (tachada) y eliminarla.
