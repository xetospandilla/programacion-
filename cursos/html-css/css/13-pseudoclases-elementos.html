Lección 23: Pseudo-clases y pseudo-elementos

Estados de los elementos (:hover, foco, marcado, desactivado) y contenido decorativo (::before, ::after), con el teclado y la accesibilidad en mente.

Objetivos

  • Aplicar :hover, :focus-visible, :active, :checked y :disabled.
  • Usar ::before y ::after.
  • Mantener el foco visible para quien navega con teclado.

Conocimientos previos

Selector de la lección 02 (etiquetas, clases) y formularios HTML (la lección 08 del curso), donde aparecen checkbox y campos desactivados.

1. Pseudo-clases de interacción

Una pseudo-clase (un solo :) selecciona un estado, no un elemento. Prueba estos con el ratón y con el teclado (Tab):

Enlace: al pasar el ratón cambia fondo y borde, no solo color

  • :hover: el ratón está encima. Nunca debe ser la única señal (móviles no tienen hover).
  • :focus-visible: el foco llega POR TECLADO. Es el que se debe estilar con un anillo visible. :focus también incluye el clic del ratón y puede resultar molesto.
  • :active: el instante exacto de la pulsación (antes de soltar).

Accesibilidad de foco: nunca hagas outline: none sin ofrecer otra alternativa visible (fondo + borde, o un anillo con outline-offset). Quien navega solo con teclado necesita ver dónde está.

2. Estados de formulario: :checked y :disabled

En un checkbox, :checked se activa cuando está marcado; :disabled selecciona campos desactivados (con el atributo disabled en el HTML).

Este texto responde al estado marcado (:checked).

(estilo gris por :disabled; además el HTML ya lo desactiva)

.d-check:checked ~ .d-estado-check {
    font-weight: bold;
    color: #2e7d32;
}

El combinador ~ elige hermanos posteriores del checkbox dentro del mismo contenedor.

3. Pseudo-elementos: ::before y ::after

Un pseudo-elemento (doble ::) genera una caja extra delante (::before) o detrás (::after) del contenido. Sin la propiedad content (texto o vacía "") no se crean.

Un titular con decoración generada

Las comillas » y « las crea CSS, no existen en el HTML: ::before y ::after con content.

.d-titulo::before { content: "» "; color: #b5332e; }
.d-titulo::after  { content: " «"; color: #b5332e; }

Se usan mucho para iconos, viñetas, bordes decorativos y «flechas» de acordeones. El contenido generado se lee por los lectores de pantalla según el navegador: no pongas información importante solo ahí.

Errores frecuentes y cómo corregirlos

  • outline: none sin alternativa: rompe la navegación por teclado. Estila :focus-visible con un anillo y outline-offset.
  • Cambiar solo el color con :hover: insuficiente (y para daltónicos, invisible). Añade otra señal: fondo, borde, desplazamiento.
  • ::before sin content: no aparece. content: "" con un fondo también sirve.
  • Usar ::before para texto de lectura: el contenido generado no es contenido real; guarda lo importante en el HTML.
  • :focus en vez de :focus-visible para todo: :focus pinta también con el clic; reserva el anillo llamativo para :focus-visible.

Ejercicios

Parte de mi-estados.html.

  1. Fácil — hover con dos señales: un enlace que al pasar el ratón cambie color Y fondo.
  2. Medio — foco por teclado: un botón con :focus-visible con anillo exterior (outline-offset). Pruébalo con Tab.
  3. Difícil — formulario con estados: un checkbox cuyo hermano posterior cambie con :checked, y un campo disabled con estilo claro (y texto que lo anuncie, no solo gris).

Soluciones razonadas

Intenta los ejercicios antes de leer esto.

Ejercicio 1

a:hover { background: #e8f0fe; color: #1f4e79; }

Ejercicio 2

button:focus-visible {
    outline: 3px solid #b5332e;
    outline-offset: 2px;
}

Ejercicio 3

.chk:checked ~ p { font-weight: bold; color: #2e7d32; }
input:disabled + span { color: #888; font-style: italic; }

El + elige el hermano inmediato; el texto «(campo desactivado)» junto al valor da la información sin depender del color.

Resumen y autoevaluación

Las pseudo-clases capturan estados ( :hover, :focus-visible, :active, :checked, :disabled) y los pseudo-elementos generan cajas decorativas (::before/::after con content). La regla de oro: nunca retirar el foco ni comunicar solo con color.
