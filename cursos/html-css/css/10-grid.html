Lección 20: CSS Grid

Grid maqueta en dos dimensiones a la vez: filas Y columnas. Si Flexbox reparte una línea, Grid define la rejilla completa de la página (o de una zona).

Objetivos

  • Definir filas y columnas con grid-template-columns / grid-template-rows.
  • Repartir el espacio con la unidad fr y con repeat() y minmax().
  • Separar con gap.
  • Colocar elementos concretos en la cuadrícula.

Conocimientos previos

Flexbox (teoría y práctica): Grid no lo sustituye, lo complementa. Flexbox = una línea; Grid = la rejilla.

1. Filas y columnas

Con display: grid y grid-template-columns (o -rows) defines las pistas. Cada valor es una pista; con gap las separas:

.gr { display: grid; grid-template-columns: 100px 1fr 2fr; gap: 4px; }
100px fija
1fr (un tercio del resto)
2fr (dos tercios del resto)

La unidad fr (fracción) reparte el espacio que sobra tras las pistas fijas: aquí, la segunda columna recibe la mitad que la tercera.

2. repeat() y minmax()

repeat(3, 1fr) repite una pista tres veces. Con minmax(mín, máx) la pista se encoge hasta el mínimo y crece hasta el máximo:

/* tres columnas iguales */
grid-template-columns: repeat(3, 1fr);
/* columna que no baja de 220px ni se dispara sin límite */
grid-template-columns: 1fr minmax(220px, 1fr) 1fr;
1
2
3
4
5
6

Con repeat(auto-fit, minmax(180px, 1fr)) la cuadrícula crea las columnas que caben según el ancho: el patrón de «galería adaptable» sin media queries.

3. Colocación de elementos

Por defecto, cada elemento ocupa la siguiente celda libre (autoplacement). Se puede colocar a mano con grid-column/grid-row usando inicio / fin o span n:

.item-a { grid-column: 1 / 3; }      /* de la línea 1 a la 3 */
.item-b { grid-column: 3; grid-row: 1 / 3; }
A: ocupa dos columnas
B: columna 3, dos filas de alto
C: normal
D: normal

Las líneas están numeradas (1 = borde inicial); un elemento que va de la línea 1 a la 3 abarca dos columnas.

4. Grid vs. Flexbox: cuándo cada uno

  • Una línea (menú, barra, tarjetas en fila): Flexbox.
  • Rejilla bidimensional (página completa, galerías, paneles): Grid.
  • Combinar: es normal un contenedor grid con ítems flex dentro, y al revés.

Errores frecuentes y cómo corregirlos

  • «fr» con px sin mezclar bien: grid-template-columns: 200px 1fr está bien; el error es calcular a mano el «1fr» — lo hace el navegador.
  • Elementos fuera de lugar al usar grid-column: revisa que las líneas inicio/fin existen: de 1 a 3 en un grid de 3 columnas abarca columnas 1 y 2 (3 son las líneas externas).
  • Olvidar gap y «todo pegado»: pon gap en el contenedor, no márgenes en cada celda.
  • Grid para todo: un menú de una línea es más simple con flex; la sobre-ingeniería complica.

Ejercicios

Parte de mi-grid.html.

  1. Fácil — tres columnas: un grid con repeat(3, 1fr) y seis celdas numeradas.
  2. Medio — minmax: sustituye por repeat(auto-fit, minmax(150px, 1fr)) y encoge la ventana: las celdas bajan de fila solas.
  3. Difícil — colocación: en un grid de 3 columnas haz que un elemento ocupe dos columnas y otro dos filas (usa span).

Soluciones razonadas

Intenta los ejercicios antes de leer esto.

Ejercicio 1

.gr { display: grid; grid-template-columns: repeat(3, 1fr); gap: 4px; }

Ejercicio 2

.gr { display: grid;
    grid-template-columns: repeat(auto-fit, minmax(150px, 1fr)); }

auto-fit crea tantas pistas de 150px como caben y reparte el sobrante entre ellas.

Ejercicio 3

.ancho { grid-column: span 2; }
.alto  { grid-row: span 2; }

span evita contar líneas a mano: «abarca dos pistas», sin importar dónde empiece.

Resumen y autoevaluación

Grid define filas y columnas (grid-template-*), reparte el espacio con fr, repeat() y minmax(), separa con gap y coloca elementos con grid-column/grid-row. Para rejillas bidimensionales; flex para líneas sencillas.
