Lección 11: Introducción a CSS

CSS es el lenguaje que pinta las páginas: colores, tamaños, márgenes y tipografía. Aquí veremos qué es, cómo se escribe una regla y las tres formas de aplicarlo.

Objetivos

  • Explicar qué es CSS y qué problema resuelve.
  • Reconocer la anatomía de una regla: selector, propiedad y valor.
  • Aplicar CSS en línea, en bloque style y en hoja externa.
  • Razonar por qué la hoja externa es la forma recomendada.

Conocimientos previos

El bloque HTML de este curso, sobre todo la introducción (qué es una etiqueta y sus atributos) y la semántica estructural (las zonas header, main, footer...).

1. ¿Qué es CSS?

CSS significa Cascading Style Sheets (Hojas de Estilo en Cascada). Es el lenguaje con el que se describe cómo se ve el contenido que marcó HTML: colores, tipografía, espacios, bordes, tamaños... HTML dice qué hay; CSS dice cómo se presenta.

CSS no se ejecuta: el navegador lo lee y lo aplica. Y funciona por reglas: cada regla elige qué elementos pintar (el selector) y con qué estilo (propiedades y valores).

/* Anatomía de una regla CSS */
selector {
    propiedad: valor;
}

Ejemplo real:

p {
    color: #2e7d32;   /* el texto de todos los <p> será verde */
    font-size: 1.1rem;
}

El selector p elige todos los párrafos; la pareja propiedad: valor es una declaración; el conjunto de declaraciones entre llaves es el bloque.

2. Tres formas de aplicar CSS

a) Estilo en línea (atributo style)

Se escribe directamente en la etiqueta:

<p style="color: #b5332e; font-weight: bold;">
    Este párrafo va en rojo y negrita.
</p>

Este párrafo va en rojo y negrita.

Es lo más directo, pero mezcla presentación con contenido y no se reutiliza: solo vale para esa etiqueta.

b) Bloque <style> en el head

Agrupa varias reglas dentro de la propia página:

<style>
    .demo-style p {
        color: #2e7d32;
        font-weight: bold;
    }
</style>

Está en el head de esta página (con un comentario de demostración). Resultado:

Este párrafo lo pinta el bloque style: verde y negrita.

Sirve para páginas sueltas, pero los estilos no se comparten entre páginas.

c) Hoja externa con <link>

<link rel="stylesheet" href="ejemplos/01-introduccion-css.css">

Las reglas viven en un archivo .css aparte y se enlazan desde el head. Esta página ya lo hace: la zona de abajo la pinta la hoja externa.

Párrafo coloreado por la hoja externa: azul y con borde izquierdo.

Otro párrafo: la regla .demo-externa p los elige a todos.

Este lleva la clase «destacado»: la hoja le añade fondo y negrita.

Un enlace a la portada del curso también lo pinta la hoja externa (color burdeos).

3. Por qué conviene la hoja externa

  • Separación de responsabilidades: el HTML queda limpio de estilos; si mañana cambias el diseño, tocas solo el .css.
  • Reutilización: el mismo archivo se enlaza desde todas las páginas; el diseño es uniforme.
  • Mantenimiento: una sola fuente de verdad; no hay que buscar estilos esparcidos por 20 páginas.
  • Rendimiento: el navegador descarga la hoja una vez y la reutiliza (caché) en lugar de repetir estilos en cada documento.

El estilo en línea queda reservado a cosas puntualísimas (y suele ser señal de que conviene una clase); el bloque style, a ejercicios o prototipos sueltos.

Errores frecuentes y cómo corregirlos

  • Confundir el orden de propiedad y valor: siempre propiedad: valor con dos puntos y punto y coma al final de cada declaración.
  • Olvidar las llaves o el punto y coma: la regla se rompe. Pon } al final y un ; tras cada declaración.
  • Escribir el CSS en el body: los <style> van en el head, y las hojas se enlazan también ahí.
  • Ruta del link rota: el navegador no muestra la hoja. Comprueba que la ruta relativa hacia el .css es correcta (aquí: ejemplos/01-introduccion-css.css).
  • Estilos en línea por todas partes: funciona pero no escala. Aprende a usar clases desde ya.

Ejercicios

Crea mi-primer-css.html con estructura HTML válida (recuerda la de la lección 0 del curso).

  1. Fácil — en línea: un párrafo con style="color: #d97706; font-size: 1.3rem;". Ábrelo: el texto debe verse naranja y más grande.
  2. Medio — bloque style: añade un <style> en el head con una regla p que ponga color a los párrafos y otra a un encabezado h1.
  3. Difícil — hoja externa: crea mis-estilos.css al lado de la página, escribe una regla body (fondo claro y tipografía sans-serif) y enlázala con <link> desde el head. Comprueba que se aplica.

Soluciones razonadas

Intenta los ejercicios antes de leer esto.

Ejercicio 1

<p style="color: #d97706; font-size: 1.3rem;">
    Hola con estilo en línea.
</p>

Ejercicio 2

<style>
    h1 { color: #1f4e79; }
    p  { color: #37474f; }
</style>

Las reglas van en el head, antes del body.

Ejercicio 3

<link rel="stylesheet" href="mis-estilos.css">

Y en mis-estilos.css:

body {
    background-color: #fafafa;
    font-family: sans-serif;
}

La hoja vive en la misma carpeta que la página: la ruta es solo el nombre del archivo.

Resumen y autoevaluación

CSS pinta el contenido de HTML mediante reglas (selector + propiedades). Puede aplicarse en línea, en bloque style o en hoja externa enlazada; la hoja externa es la recomendada porque separa, reutiliza y facilita el mantenimiento.
