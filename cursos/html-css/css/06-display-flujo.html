Lección 16: Display y flujo normal

Cómo se colocan las cajas unas junto a otras por defecto, y qué pasa cuando cambiamos su display, su visibility o cómo desbordan.

Objetivos

  • Explicar el flujo normal de la página (block e inline).
  • Usar display: block, inline, inline-block y none.
  • Diferenciar visibility de display.
  • Controlar el desbordamiento con overflow.

Conocimientos previos

El modelo de caja (contenido, padding, borde, margen) y los selectores. Aquí vemos cómo se colocan esas cajas.

1. El flujo normal

Sin CSS de colocación, el navegador coloca las cajas en flujo normal: de arriba abajo y de izquierda a derecha. Hay dos grandes comportamientos:

  • Block (bloque): ocupa todo el ancho disponible, se apila en vertical (párrafos, div, títulos, listas).
  • Inline (en línea): fluye dentro del texto sin romper la línea (span, a, strong). No respetan anchura ni altura.

Bloque 2 (se apila debajo)

Texto con una pieza inline y otra pieza inline: fluyen en la línea.

2. display: cambiar el comportamiento

display cambia cómo se trata un elemento:

  • block: fuerza ancho completo y salto de línea.
  • inline: fluye en línea; ignora width/height, y el padding/margin vertical no empuja a las demás cajas.
  • inline-block: en línea pero con caja respetable: admite ancho, alto, márgenes y relleno.
  • none: desaparece por completo, sin dejar hueco (se usa con JavaScript para mostrar/ocultar).

Tres cajitas inline-block con ancho y alto: se reparten la línea pero se comportan como cajas.

.caja { display: inline-block; width: 120px; height: 34px; }

La combinación estrella para hacer botones y tarjetas es inline-block; más adelante (lección de flexbox) se hará casi todo con display: flex.

3. visibility: ocultar sin mover a los demás

visibility: hidden oculta el contenido pero deja el hueco; visibility: visible lo restaura. No confundir con display: none, que retira el elemento del flujo (los vecinos se juntan).

Regla práctica: para animar u ocultar de verdad, display: none + block; cuando el elemento debe seguir ocupando sitio (por ejemplo, mensajes de carga), visibility.

4. overflow en el flujo

Cuando el contenido no cabe en una caja con ancho/alto fijo, sale por defecto (overflow: visible). Se decide recortar (hidden), desplazar (auto, scroll) o dejar que se vea.

Texto largo dentro de una caja pequeña: aparece una barra de desplazamiento porque overflow vale auto y el contenido no cabe.

El overflow también crea un «contexto»: los hijos que se salen ya no desbordan más allá de la caja. Útil para contener esquinas redondeadas o elementos flotantes.

Errores frecuentes y cómo corregirlos

  • «Puse width a un enlace y no cambia»: es inline; usa display: inline-block (o block) para que respete el ancho.
  • Esperar que visibility: hidden ahorre espacio: no; usa display: none si el espacio debe cerrarse.
  • Margen vertical «que no empuja»: en elementos inline no desplaza; conviértelos a inline-block/block.
  • Contenido cortado «de golpe»: revisa overflow: hidden en alguna caja contenedora de la que no te acordabas.

Ejercicios

Parte de mi-flujo.html con estructura mínima.

  1. Fácil — apilar bloques: tres div con fondo distinto. Obsérvalos apilados y di qué display tienen por defecto.
  2. Medio — inline-block: convierte los mismos tres div en inline-block con ancho de 30%. ¿Qué pasa con la suma de anchos y los huecos?
  3. Difícil — ocultar bien: crea una línea oculta con visibility y otra con display: none; comenta en el HTML qué hueco deja cada una.

Soluciones razonadas

Intenta los ejercicios antes de leer esto.

Ejercicio 1

Los div son block: ocupan el ancho completo y se apilan. No hace falta CSS.

Ejercicio 2

.tres { display: inline-block; width: 31%; }

Tres de 31% suman 93%: entre medias hay «huecos de línea» (espacios en blanco del HTML) que suman; por eso se usa 3% o menos de margen. Es la época pre-flexbox de maquetar.

Ejercicio 3

<div class="linea">Visible</div>
<div class="linea oculta-espacio">Visibility hidden</div>
<div class="linea oculta-sin-espacio">Display none</div>
<div class="linea">Después</div>

/* .oculta-espacio { visibility: hidden; } -> deja hueco
   .oculta-sin-espacio { display: none; } -> no deja hueco */

Resumen y autoevaluación

El flujo normal apila los bloques y encadena los elementos en línea. display cambia ese comportamiento (block, inline, inline-block, none), visibility oculta dejando el hueco, y overflow decide qué ocurre con el contenido que desborda.
