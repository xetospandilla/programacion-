2. Las decisiones, una a una

Navegación (.p-nav):

.p-nav {
    display: flex;          /* hijos en línea */
    align-items: center;    /* same línea vertical */
    gap: 1rem;              /* separación uniforme */
    flex-wrap: wrap;        /* en móvil, el menú baja sin romperse */
}
.p-nav .marca { margin-right: auto; }  /* empuja el resto a la derecha */

margin-right: auto en el logo absorbe todo el espacio sobrante: los enlaces quedan pegados a la derecha sin calcular anchos.

Tarjetas (.p-tarjetas):

.p-tarjetas { display: flex; flex-wrap: wrap; gap: 1rem; }
.p-tarjeta { flex: 1 1 180px; }

Base mínima de 180px: caben 2-3 por línea según el ancho y el wrap las baja de forma natural. Es el "grid de tarjetas" sin Grid.

Fila de datos (.p-fila):

.p-fila {
    display: flex;
    justify-content: space-between;  /* extremos pegados, huecos iguales */
    align-items: center;
    flex-wrap: wrap;
    gap: 0.6rem;
}

Las etiquetas se reparten todo el ancho; al encoger, hacen wrap y quedan alineadas.

Errores frecuentes y cómo corregirlos

  • Menú que se rompe en móvil: falta flex-wrap: wrap en el nav o en la fila.
  • Botón del menú que se cae: con margin-left: auto en la marca debe quedar siempre pegado a la derecha; revisa que el `` de la marca sea el primero.
  • Tarjetas con alturas dispares que se ven raras: stretch (por defecto) iguala la altura de cada línea; si prefieres que no estiren, usa align-items: flex-start.
  • Gap no aplicado: gap funciona solo en contenedores flex/grid; si el elemento no es flex, no separa nada.

Ejercicios

  1. Fácil — variar la base: cambia flex: 1 1 180px por 1 1 240px y observa cuántas tarjetas entran por línea. Anótalo.
  2. Medio — menú con dos botones: añade un segundo botón al nav y comprueba que el margin-right: auto de la marca sigue empujando a ambos a la derecha.
  3. Difícil — fila de datos vertical en móvil: añade una media query sencilla (se ve en la lección de responsive) que ponga flex-direction: column a la fila cuando la pantalla sea muy estrecha.

Soluciones razonadas

Intenta los ejercicios antes de leer esto.

Ejercicio 1

Con base 240px entran dos tarjetas en la mayoría de pantallas en vez de tres o cuatro. La base mínima es «cuánto espacio exige cada ítem como mínimo».

Ejercicio 2

<a href="#" class="boton">Contacto</a>
<a href="#" class="boton secundario">Ayuda</a>

Con la marca usando margin-right: auto, todo lo que venga después queda a la derecha, da igual cuántos enlaces haya.

Ejercicio 3

@media (max-width: 420px) {
    .p-fila { flex-direction: column; align-items: flex-start; }
}

En pantallas muy estrechas las etiquetas se apilan en vertical y desaparece la barra «ancha».
