Lección 14: Colores, unidades y tipografía

El vocabulario visual de CSS: cómo escribir colores, las unidades de medida (y cuándo usar cada una) y las reglas de legibilidad del texto.

Objetivos

  • Escribir colores con nombres, hexadecimal, RGB y HSL.
  • Distinguir unidades absolutas y relativas: px, %, em, rem, vw, vh.
  • Componer texto legible: familia, tamaño, interlineado y alineación.

Conocimientos previos

Las lecciones de introducción y selectores: aquí se llenan de contenido las propiedades.

1. Cómo escribir colores

Hay cuatro formas habituales, todas válidas:

  • Nombre: red, navy, teal... Limitado, pero legible para pocas decenas de colores.
  • Hexadecimal: #ff0000 (rojo), #1f4e79 (azul oscuro). Pares RR GG BB; cada par en hexadecimal (00 a ff). Se puede abreviar: #f00 es igual que #ff0000.
  • RGB: rgb(255, 0, 0); cada canal de 0 a 255.
  • HSL: hsl(0, 100%, 50%); tono (0-360, ángulo de la rueda), saturación y luminosidad en porcentaje. Muy cómodo para variar claridad.

Las cuatro formas escriben el mismo rojo:

red | #ff0000 | rgb(255, 0, 0) | hsl(0, 100%, 50%)

A rgb() puede añadírsele transparencia con rgba(0, 0, 0, 0.5) (el último número, de 0 a 1, es la opacidad).

2. Unidades de medida

Las absolutas son fijas; las relativas dependen de un contexto (el padre, la raíz o la ventana). En pantallas se usa casi siempre relativo.

Unidad Tipo ¿De qué depende?
px Absoluta Píxeles de pantalla; fija y predecible
% Relativa Del elemento padre (ancho, alto, fuente...)
em Relativa Del tamaño de letra de SU padre (se encadena)
rem Relativa Del tamaño de letra de la raíz (html, normalmente 16px)
vw / vh Relativa Del ancho/alto de la ventana (1vw = 1% del ancho)

Texto base: font-size: 16px. Hijo con 1.5em: 1,5 × el tamaño de SU padre ⇒ 24px.

Otro texto base. Hijo con 1.5rem: 1,5 × el tamaño de la raíz (16px) ⇒ 24px, sin encadenarse al padre.

Esta banda mide 50vw: la mitad del ancho de la ventana, cambie o no.

Regla práctica: em se encadena (un em dentro de un em se multiplica), así que para tamaños de letra suele preferirse rem, de comportamiento predecible. em sigue siendo útil para paddings proporcionales al propio texto.

3. Tipografía legible

Consejos de base, todos demostrados debajo:

  • font-family: lista de familias en orden; el navegador usa la primera disponible. Acaba siempre con una genérica (serif, sans-serif, monospace).
  • font-size: en rem para que respete la preferencia del usuario.
  • line-height: interlineado de 1.5 en adelante para párrafos largos.
  • text-align: left / right / center / justify.
  • text-transform y letter-spacing: para rótulos y títulos.

Un titular con la familia serif (Georgia)

Texto con line-height: 2: el interlineado holgado hace que las líneas largas dejen de perderse.

Alineación a la derecha (text-align: right) — adecuada para textos cortos o citas, no para párrafos largos.

Texto en mayúsculas con espaciado entre letras, típico de rótulos y menús.

Texto pequeño (0.8rem) con color gris: sigue siendo legible por el contraste, pero pide ser corto.

La legibilidad depende del contraste (texto oscuro sobre fondo claro y al revés), de no abusar de párrafos muy largos (max-width alrededor de 60-70 caracteres por línea) y de no cifrar información solo con color (algunas personas no distinguen rojo y verde).

Errores frecuentes y cómo corregirlos

  • Confundir em y rem: em mira al padre (se encadena), rem a la raíz. Si un em dentro de otro em «se dispara», ese es el motivo.
  • Usar px para tamaños de letra: no respeta la preferencia de tamaño del navegador. Prefiere rem.
  • Hex sin # o con valores inválidos: ff0000 (sin #) no funciona; tampoco #ff00. Escribe siempre 3 o 6 dígitos con la almohadilla.
  • Familias sin alternativa genérica: font-family: Georgia deja la página rota si no existe. Termina con serif o sans-serif.
  • Miles de píxeles de ancho: las lecturas de 100% de ancho son cansadas; estrecha con max-width.

Ejercicios

Parte de mi-tipografia.html con su hoja mi-tipografia.css enlazada.

  1. Fácil — colores: escribe «manchas» con los cuatro formatos del mismo tono (por ejemplo, un azul) y anota qué formato se te hace más legible.
  2. Medio — unidades: un párrafo base de 16px; dentro, un span con 1.5em y otro con 1.5rem. Predice el resultado antes de abrirlo.
  3. Difícil — párrafo legible: compón un párrafo con font-size: 1rem, line-height: 1.6, max-width: 35rem y un titular con letter-spacing. Compara la lectura con y sin esas reglas.

Soluciones razonadas

Intenta los ejercicios antes de leer esto.

Ejercicio 1

.azul { color: blue; }           /* nombre */
.azul { color: #0000ff; }        /* hex completo o #00f */
.azul { color: rgb(0, 0, 255); } /* rgb */
.azul { color: hsl(240, 100%, 50%); } /* hsl: 240 = azul */

Hex y rgb son los más usados; hsl es muy cómodo para generar escalas de un tono.

Ejercicio 2

.hijo-em  { font-size: 1.5em; }  /* = 24px si el padre es 16px */
.hijo-rem { font-size: 1.5rem; } /* = 24px siempre que la raíz sea 16px */

La diferencia aparece cuando hay anidamiento: em multiplica sobre el padre inmediato.

Ejercicio 3

.parrafo {
    font-size: 1rem;
    line-height: 1.6;
    max-width: 35rem;   /* unas 60-70 letras por línea */
}

Ancho y interlineado moderados: es el «reglaje» clásico de los textos que se leen bien.

Resumen y autoevaluación

Los colores se escriben con nombre, hex, rgb o hsl. Las unidades relativas (%, em, rem, vw, vh) se adaptan a su contexto; rem es la opción por defecto para tamaños de letra. Un texto legible combina familia con alternativas, interlineado holgado y líneas no demasiado largas.
