Lección 17: Posicionamiento

Sacar cajas del flujo normal y moverlas con precisión: relative, absolute, fixed, sticky y el orden de apilado con z-index.

Ejemplo sticky: esta barra se queda pegada al borde superior mientras haces scroll por la página.

Objetivos

  • Distinguir los cinco valores de position.
  • Entender el contexto de posicionamiento (el «marco» del absolute).
  • Controlar qué elemento tapa a cuál con z-index.

Conocimientos previos

La lección de display y flujo: aquí movemos las cajas fuera de ese flujo.

1. static: el punto de partida

Es el valor por defecto: la caja sigue el flujo normal. Si le pones top/left/etc., se ignoran: las propiedades de desplazamiento solo actúan con los otros valores.

2. relative: desplazar sin salirse

La caja se mueve respecto a su posición normal con top, right, bottom, left. El hueco original se conserva (los vecinos no se enteran del movimiento).

Caja en flujo normal
Esta está desplazada 14px hacia abajo y 22px a la derecha (relative)
Tercera caja normal: el hueco de la anterior sigue ocupado

3. absolute y el contexto de posicionamiento

absolute saca la caja del flujo (los vecinos la ignoran) y la posiciona respecto a su ancestro posicionado más cercano: el primer ancestro con position distinto de static (normalmente un position: relative sin desplazamiento). Si no existe, toma la ventana del navegador.

El escenario tiene position: relative: es el contexto.
Esta caja es absolute: anclada a 10px del borde superior y 10px del derecho del escenario.

Error clásico: el absolute «huye» al fondo de la página porque el contenedor no está posicionado. Dale position: relative al contenedor (sin desplazarlo) y el anclaje será ese.

4. fixed y sticky

fixed ancla la caja a la ventana (no al documento): permanece inmóvil al hacer scroll. Fíjate en la cajita verde de la esquina inferior derecha de esta página: es un ejemplo real de fixed.

Demo fixed: fija a la ventana (abajo a la derecha).

sticky es híbrido: se comporta como relative hasta que el scroll lo alcanza, y entonces se queda «pegado» (recuerda la barra azul arriba de esta página). Útil para menús y titulares persistentes.

5. z-index: quién tapa a quién

Cuando dos cajas coinciden, la que aparece más tarde en el HTML suele tapar a la anterior. z-index ordena el eje Z (a mayor número, más arriba), y solo funciona en elementos posicionados (o flex/grid).

Números pequeños y con orden de importancia, no «hasta que se vea»: la escalada de z-index acaba siendo inmantenible.

Errores frecuentes y cómo corregirlos

  • Absolute «perdido»: su ancestro no está posicionado. Confirma el position: relative del contenedor.
  • z-index sin efecto: el elemento es static; pónle position: relative (o flex/grid) para que participe del apilado.
  • Fixed que no se queda fijo: si un ancestro tiene transform/filter, se convierte en su contexto y ya no es la ventana.
  • Modales que quedan bajo el contenido: revisa que el modal positionado tenga el z-index mayor del contexto, no solo de la página.

Ejercicios

Parte de mi-posicion.html.

  1. Fácil — relative: dos párrafos; desplaza el segundo 12px abajo y 20px a la izquierda. Observa el espacio que conserva.
  2. Medio — absolute anclado: un contenedor con position: relative y una «etiqueta» absolute en su esquina superior derecha.
  3. Difícil — foco con z-index: dos cajas que se solapan con z-index distintos y explica en un comentario por qué una queda encima.

Soluciones razonadas

Intenta los ejercicios antes de leer esto.

Ejercicio 1

.segundo { position: relative; top: 12px; left: -20px; }

left negativo desplaza a la izquierda; el hueco original permanece.

Ejercicio 2

.contenedor { position: relative; }
.etiqueta { position: absolute; top: 0; right: 0; }

La etiqueta se ancla al contenedor porque él es su ancestro posicionado más cercano.

Ejercicio 3

.encima { position: relative; z-index: 3; }
.debajo { position: relative; z-index: 1; }

Entre posicionados, el del z-index mayor se dibuja encima; a igualdad, gana el último del HTML.

Resumen y autoevaluación

position decide el anclaje: static (flujo), relative (desplaza desde su sitio), absolute (fuera del flujo, anclado al ancestro posicionado), fixed (a la ventana) y sticky (se pega al hacer scroll). El z-index ordena el apilado entre posicionados.
