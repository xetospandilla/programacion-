Lección 12: Selectores

El selector es la parte de la regla que decide a qué elementos se aplica el estilo. Hay muchos tipos: aquí vemos los básicos, todos con ejemplos visibles en esta misma página.

Objetivos

  • Aplicar estilos por etiqueta, por clase y por ID.
  • Combinar selectores: descendiente, hijo directo y hermano adyacente.
  • Agrupar reglas con comas.
  • Seleccionar por atributos.
  • Saber cuándo conviene clase sobre ID.

Conocimientos previos

La lección de introducción a CSS: reglas, propiedades y hoja externa. Y del bloque HTML, conocer class e id como atributos.

1. La zona de demostración

Toda la demo de esta lección vive en el bloque siguiente, pintado por la hoja ejemplos/02-selectores.css. Cada regla de esa hoja demuestra un selector; veamos cuál hace qué.

Un águila: lleva la clase «ave».

Una gaviota: también lleva la clase «ave».

Mi tortuga: lleva el id «mascota».

Párrafo hijo directo de un div: le añade fondo la regla #zoo-demo div > p.

Hermano adyacente del h3: la regla #zoo-demo h3 + p lo pinta morado.

Segundo párrafo: NO es adyacente al h3, así que no cambia.

2. Por etiqueta, clase e ID

  • Etiqueta: p, h1, a... aplica a todos los elementos con esa etiqueta. Es el más general.
  • Clase: .ave (un punto delante). La clase se pone con el atributo class="ave" y puede repetirse en muchos elementos. En la demo, las aves quedan azules y en negrita.
  • ID: #mascota (una almohadilla). Es único en la página. En la demo, la tortuga tiene borde verde discontinuo.
.ave { color: #1565c0; font-weight: bold; }
#mascota { border: 2px dashed #2e7d32; }

Regla práctica: usa clases para estilos; reserva los ID para anclar JavaScript o enlaces de página. Un ID duplicado rompe el documento y complica el CSS.

3. Descendiente y combinadores

  • Descendiente (espacio): #zoo-demo p elige todo p que esté DENTRO de #zoo-demo, a cualquier profundidad. Es la forma de acotar estilos sin tocar al resto.
  • Hijo directo (>): #zoo-demo div > p elige solo los p que son hijos INMEDIATOS del div (el de la demo tiene fondo verde claro).
  • Hermano adyacente (+): #zoo-demo h3 + p elige el primer p que viene justo después de un h3 (el de la demo, morado).
#zoo-demo p        { color: #37474f; }   /* descendiente */
#zoo-demo div > p { background: #f3f8f3; }  /* hijo directo */
#zoo-demo h3 + p   { color: #6a1b9a; }      /* hermano adyacente */

4. Atributos y agrupación

Selector de atributo: entre corchetes se indica el atributo y, opcionalmente, su valor o una parte de él:

input[type="text"] { border: 2px solid #b0bec5; }
a[href^="02-"]     { background: #fff8dc; }  /* href que EMPIEZA por 02- */

Hay operadores como ^= (empieza por), $= (termina en) y *= (contiene). El campo de texto de la demo y el enlace «02-» los aplican.

Agrupación con comas: si dos selectores comparten reglas, se ponen juntos:

#zoo-demo h2, #zoo-demo h3 { color: #37474f; }

El encabezado «Mi zoológico» y el «Alimentación» comparten el mismo color gris y tipografía.

Errores frecuentes y cómo corregirlos

  • Espacio entre el punto y la clase o la almohadilla: . ave no funciona; debe ser .ave.
  • Confundir descendiente con hijo: el espacio elige a cualquier profundidad; > solo al nivel inmediato.
  • Repetir un ID: los IDs son únicos; dos elementos con el mismo id invalidan la página.
  • Reglas que no se aplican: revisa que el elemento tenga la clase/id escritos EXACTAMENTE igual en el HTML y en el CSS (mayúsculas incluidas).
  • Selectores demasiado largos: #a #b .c > p > span es frágil: cualquier cambio de estructura lo rompe. Prefiere clases.

Ejercicios

Parte de mi-selectores.html con la estructura mínima y una hoja mi-selectores.css enlazada.

  1. Fácil — etiqueta y clase: haz que todos los h2 sean granate y que una clase .resaltado ponga fondo amarillo claro a dos párrafos.
  2. Medio — descendiente y combinadores: dentro de un <div class="caja"> colorea los párrafos descendientes y añade un fondo distinto al hijo directo con >. Explica en un comentario tu elección.
  3. Difícil — atributos: da borde azul a los enlaces cuyo href termine en .pdf ($=) y fondo a los inputs de tipo email.

Soluciones razonadas

Intenta los ejercicios antes de leer esto.

Ejercicio 1

h2 { color: #800000; }
.resaltado { background-color: #fff9c4; }

La clase puede usarse en varios elementos a la vez, por eso «dos párrafos» comparten la misma regla.

Ejercicio 2

.caja p          { color: #1f4e79; }
.caja div > p   { background-color: #e8f0fe; }

El primer selector toca todos los párrafos de la caja; el segundo, solo los hijos directos de un div interno.

Ejercicio 3

a[href$=".pdf"]      { border: 2px solid #1565c0; }
input[type="email"] { background-color: #e8f0fe; }

$= significa «termina en»; ^= sería «empieza por». El atributo va entero entre corchetes.

Resumen y autoevaluación

Los selectores básicos son etiqueta, clase (.) e ID (#). Con el espacio se eligen descendientes, con > hijos directos y con + hermanos adyacentes. Los corchetes seleccionan por atributos y las comas agrupan. Las clases son la herramienta de uso habitual; los ID, excepción.
