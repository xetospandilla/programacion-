Lección 21: Grid en la práctica

Maquetar una página completa con grid-template-areas: así se describe el diseño con palabras, y una sola media query lo convierte en móvil. La hoja es ejemplos/11-grid-practica.css.

Objetivos

  • Definir áreas de diseño con grid-template-areas.
  • Asignar cada zona con grid-area.
  • Adaptar la maqueta a pantallas pequeñas con un media query.

Conocimientos previos

La teoría de Grid (pistas, fr, repeat) y la estructura semántica de la lección HTML semántica. La media query se explica a fondo en la lección de responsive, pero aquí ya la usamos.

1. La maqueta completa

El contenedor define la rejilla con grid-template-areas: cada fila entre comillas, cada palabra es un área. La misma palabra en varias posiciones hace que el área ocupe varias celdas (aquí, «cabecera» y «pie» cruzan las tres columnas).

.g-cuadricula {
    display: grid;
    grid-template-areas:
        "cabecera  cabecera  cabecera"
        "navegacion principal lateral"
        "pie       pie       pie";
    grid-template-columns: 1fr 3fr 1fr;
    gap: 0.6rem;
}

Acerca

Contenido principal

El área «principal» recibe la columna central, la más ancha (3fr) porque es el contenido.

Lateral

Notas, enlaces o publicidad; columna estrecha (1fr).

Pie de página

Cada zona se asigna con grid-area con el mismo nombre elegido (no importa el orden del HTML):

.g-cabecera   { grid-area: cabecera; }
.g-navegacion { grid-area: navegacion; }
.g-principal  { grid-area: principal; }
.g-lateral    { grid-area: lateral; }
.g-pie        { grid-area: pie; }

2. La adaptación a pantallas pequeñas

Un solo media query reordena las áreas en una columna. El texto del área «dibuja» el nuevo diseño:

@media (max-width: 640px) {
    .g-cuadricula {
        grid-template-areas:
            "cabecera"
            "navegacion"
            "principal"
            "lateral"
            "pie";
        grid-template-columns: 1fr;
    }
}

Reduce la ventana del navegador por debajo de 640px: la maqueta pasa de tres columnas a una sola, con la navegación antes que el contenido (se ve arriba, por el orden de las áreas).

Por qué areas y no columnas numeradas: al cambiar una media query, todo el diseño se reordena sin tocar el HTML ni mover elementos uno a uno. Es legible y mantenible.

Errores frecuentes y cómo corregirlos

  • «grid-area» sin efecto: el elemento debe ser hijo DIRECTO del contenedor grid, y el nombre tiene que coincidir exactamente (mayúsculas cuentan).
  • Rectángulos imposibles: un área debe ser un rectángulo. «cabecera pie cabecera» en una fila no se puede: cada área ocupa un bloque contiguo.
  • Huecos vacíos en el área: si dejas una celda sin nombre en el template, esa celda queda vacía; usa puntos (.) para marcar «vacía» a propósito.
  • Media query que no dispara: revisa la unidad (640px) y que la query venga después de las reglas base en la misma hoja.

Ejercicios

  1. Fácil — mover el lateral: cambia el template para que el lateral esté a la izquierda y la navegación a la derecha. Solo texto del template, no propriedades nuevas.
  2. Medio — fila extra: añade una zona «banner» que cruce las tres columnas entre la cabecera y el cuerpo (nueva fila en el template + un elemento con su grid-area).
  3. Difícil — móvil con menú primero: en el media query, coloca la navegación de nuevo en primer lugar tras la cabecera (ya está) y elimina la columna lateral dejando solo 5 filas.

Soluciones razonadas

Intenta los ejercicios antes de leer esto.

Ejercicio 1

grid-template-areas:
    "cabecera cabecera cabecera"
    "lateral principal navegacion"
    "pie pie pie";

Las columnas se reordenan solo cambiando palabras: el lateral (1fr) queda a la izquierda del contenido.

Ejercicio 2

grid-template-areas:
    "cabecera cabecera cabecera"
    "banner banner banner"
    "navegacion principal lateral"
    "pie pie pie";
/* y en el HTML: <div class="g-banner" style="grid-area:banner">... */

Ejercicio 3

@media (max-width: 640px) {
    .g-cuadricula {
        grid-template-areas:
            "cabecera"
            "navegacion"
            "principal"
            "lateral"
            "pie";
        grid-template-columns: 1fr;
    }
}

Es el mismo del curso: una columna, cinco filas, sin lateral «pegado» al contenido porque todo se apila.

Resumen y autoevaluación

Las áreas hacen que la maqueta se describa con texto: grid-template-areas dibuja la rejilla y cada elemento se asigna con grid-area. La misma maqueta se vuelve móvil reescribiendo el template dentro de un media query.
