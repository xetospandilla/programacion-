Lección 24: Variables CSS

Guardar valores con nombre (colores, espacios, radios) y usarlos con var(): cambiar el tema de todo el sitio tocando solo la definición.

Objetivos

  • Definir propiedades personalizadas en :root.
  • Usarlas con var(), con valor por defecto.
  • Entender su herencia y reasignación local.
  • Mantener colores y espacios coherentes sin repetirlos.

Conocimientos previos

Selectores (02) y cascada (03): las variables se heredan y se reasignan como el resto de propiedades.

1. Definir y usar

Una variable CSS se escribe con dos guiones y un nombre (--color-primario), y se define en un selector normal. En :root queda disponible para toda la página:

:root {
    --color-primario: #1f4e79;
    --color-acento: #b5332e;
    --radio: 6px;
    --espacio: 0.6rem;
}

.boton {
    background: var(--color-primario);
    border-radius: var(--radio);
    padding: var(--espacio) calc(var(--espacio) * 2);
}

Con var() se lee el valor; el segundo argumento es el valor por defecto si la variable no existe: var(--color-primario, #333).

3. Herencia y reasignación

Las variables se heredan como cualquier propiedad: un valor definido en :root llega a todos los descendientes; redefinirlo en un bloque afecta solo a ese bloque y a sus hijos.

.zona-especial { --color-acento: #2e7d32; }

Esta característica es la base de los temas (claro/oscuro): se redefine un puñado de variables en una clase (o en un media query de prefers-color-scheme) y todo el sitio cambia.

Nombres con sentido: llama a las variables por SU FUNCIÓN (--color-primario, --espacio), no por su valor (--azul-1f4e79). Así el tema se puede cambiar sin tocar nombres.

Errores frecuentes y cómo corregirlos

  • Nombre sin guiones dobles: color-primario no es una variable; --color-primario sí.
  • Olvidar el paréntesis de var(): var(--x sin cerrar invalida la declaración. var(--x, #000).
  • Definir la variable en un selector que no cubre al elemento: si el elemento no es descendiente, no la recibirá como propia; usa :root para lo global.
  • Usar la variable como si fuera valor de la propiedad en que se usa: una variable guarda VALORES, no declaraciones: --borde: border:...; no funciona como propiedad.

Ejercicios

Parte de mi-tema.html.

  1. Fácil — tres variables: define en :root un color de fondo, uno de texto y un radio; aplícalos a un body y una tarjeta.
  2. Medio — valor por defecto: usa var(--color-que-no-existe, #123456) en un elemento y comprueba que usa el respaldo.
  3. Difícil — reasignación local: una clase que cambie --color-primario solo dentro de un bloque, y explica con un comentario por qué la otra tarjeta no cambia.

Soluciones razonadas

Intenta los ejercicios antes de leer esto.

Ejercicio 1

:root { --fondo: #fafafa; --texto: #222; --radio: 6px; }
body { background: var(--fondo); color: var(--texto); }
.tarjeta { border-radius: var(--radio); }

Ejercicio 2

.respaldo { color: var(--color-que-no-existe, #123456); }

El navegador usa #123456 porque la variable no está definida en ningún ancestro.

Ejercicio 3

.especial { --color-primario: #2e7d32; }
/* Solo este bloque y sus hijos leen el nuevo valor: la herencia
   empieza aquí y no "sube" al resto de la página. */

Resumen y autoevaluación

Las propiedades personalizadas (--nombre) se definen normalmente, se heredan y se leen con var(). Definidas en :root son globales; reasignadas en un bloque, locales. Son la base de los temas y de la coherencia visual.
