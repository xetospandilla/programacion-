Integrando CSS en un Archivo HTML

Esta página se ve con estilos gracias a una hoja de estilos externa (variables.css). Compara el aspecto de esta página con el de las demás lecciones del curso: aquí el fondo es claro, el título es azul y hay cajas con bordes.

Qué es CSS

CSS (Cascading Style Sheets, "hojas de estilo en cascada") es el lenguaje que define el aspecto visual de una página web: colores, tamaños, márgenes, bordes, posiciones... HTML aporta la estructura y CSS aporta el diseño.

La estructura de una regla CSS

Una regla CSS se escribe así:

selector { propiedad: valor; }

Por ejemplo, en variables.css: 

h1 { color: #1a5276; border-bottom: 3px solid #2980b9; }

El selector (h1) elige a qué elementos se aplica; la propiedad (color) indica qué se cambia; el valor (#1a5276) decide cómo queda. Cada declaración termina con punto y coma.

Tres formas de aplicar estilos

  • Hoja externa (la que usa esta página): un archivo .css aparte, enlazado con <link>.
  • Estilos internos: una etiqueta <style> dentro del propio HTML.
  • Estilos inline: un atributo style="" directamente sobre un elemento.

¿Por qué se prefiere una hoja externa?

En un proyecto organizado, una hoja externa permite separar el contenido (HTML) del diseño (CSS). Así, un mismo archivo de estilos puede aplicarse a muchas páginas, el código es más fácil de leer y de mantener, y los cambios de apariencia se hacen en un solo lugar.
