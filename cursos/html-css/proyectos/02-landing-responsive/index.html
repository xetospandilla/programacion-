Pluma: tus apuntes, ordenados

Una aplicación ficticia para organizar apuntes de clase por asignatura, sin perder nada. Este texto es de ejemplo: la web entera es un proyecto para practicar maquetación responsive.

Empezar gratis Ver detalles

Lo que hace por ti

Apuntes por asignatura

Agrupa tus notas en carpetas de colores y encuéntralas al instante.

Recordatorios

Marca fechas de exámenes y entrega de trabajos con un simple recordatorio.

Sin conexión

Trabaja sin internet: todo se guarda en tu dispositivo y se sincroniza cuando vuelves.

Pensado para estudiar

  • Búsqueda rápida entre todos tus apuntes.
  • Etiquetas para relacionar temas entre asignaturas.
  • Exportación de notas en PDF para repasar en papel.
  • Interface sencilla, lista en pocos minutos.
