Lección 10: Multimedia

Audio y vídeo con audio, video, fuentes alternativas y subtítulos. Todo con recursos locales, sin depender de internet.

Objetivos

  • Insertar audio con <audio> y controls.
  • Insertar vídeo con <video> y atributos útiles (controls, poster, width, preload).
  • Ofrecer fuentes alternativas con <source>.
  • Añadir subtítulos con <track>.

Conocimientos previos

La lección de rutas relativas: aquí referenciaremos archivos de la carpeta media/ que está un nivel por encima de html/.

1. Audio con <audio>

El ejemplo usa un archivo local incluido con el curso: media/tono-ejemplo.wav (un tono generado para poder practicar sin depender de internet).

<audio controls src="../media/tono-ejemplo.wav">
    Tu navegador no soporta el elemento &lt;audio&gt;.
</audio>

Así se ve en el navegador (pulsa el botón de reproducir):

El texto entre las etiquetas solo aparece si el navegador no soporta audio: es el contenido alternativo. El atributo controls muestra la barra de reproducción (play, pausa, volumen).

Otros atributos habituales:

  • loop: reproduce en bucle.
  • muted: empieza silenciado.
  • preload="none": no cargar el archivo hasta que el usuario lo pida (ahorra datos móviles).
  • volume no es un atributo: se controla desde la barra del navegador o con JavaScript.

2. Fuentes alternativas con <source>

Los navegadores no soportan todos los mismos formatos. La forma correcta de ofrecer varias versiones del mismo archivo es usar varios <source>: el navegador prueba cada uno y usa el primero que pueda reproducir.

<!-- El navegador elige la primera fuente que soporte -->
<audio controls>
    <source src="../media/cancion.mp3" type="audio/mpeg">
    <source src="../media/cancion.ogg" type="audio/ogg">
    Tu navegador no soporta audio.
</audio>

Principio importante: los archivos referenciados deben existir. En este curso el audio real se llama tono-ejemplo.wav (un solo formato suficiente), así que el ejemplo de arriba con dos fuentes es solo plantilla: sustituye las rutas por tus propios archivos cuando tengas varios formatos.

3. Vídeo con <video>

Un clip de vídeo real no se incluye en estos materiales por tamaño, pero puedes ver el funcionamiento completo: se muestra aquí con su póster (la imagen SVG del curso) y los controles.

<!-- El navegador solo podrá reproducir si existe un
     <source> válido; hasta entonces muestra el póster. -->
<video controls width="320"
       poster="../images/imagen-ejemplo.svg">
    <source src="../media/presentacion.mp4" type="video/mp4">
    <source src="../media/presentacion.webm" type="video/webm">
    <track kind="subtitles" src="../media/subtitulos-ejemplo.vtt"
           srclang="es" label="Español">
    Tu navegador no soporta el elemento &lt;video&gt;.
</video>

Con los archivos de ejemplo que sí existen (póster + subtítulos locales):

Observa el póster: es la imagen del curso. Los controles están disponibles; al pulsar reproducir, el navegador intentará los source y, como ese clip no existe en el curso, no avanzará. Es la señal de que el código está bien escrito y solo falta tu archivo de vídeo.

Atributos útiles: preload="none" (no bajar datos de más), muted, loop y width/height (escala el reproductor, no la calidad del archivo).

4. Subtítulos con <track>

El subtítulo se escribe en un archivo de texto aparte en formato WebVTT (extensión .vtt). El curso incluye media/subtitulos-ejemplo.vtt:

WEBVTT

00:00.000 --> 00:01.500
(Aquí suena un tono de ejemplo generado para la lección de multimedia)

El elemento <track> lo asocia al vídeo con su idioma (srclang="es") y su etiqueta visible (label="Español"). Con kind="captions" en lugar de subtitles se enfatiza que incluye también sonidos (ideal para accesibilidad). El usuario activa el subtítulo desde el propio reproductor.

Errores frecuentes y cómo corregirlos

  • Ruta rota: el archivo no se reproduce. Comprueba la ruta relativa (¿está ../ cuando el archivo está en otra carpeta?) y que el nombre y extensión coinciden exactamente.
  • Formato no soportado: un solo formato viejo puede no abrirse en algún navegador. Ofrece alternativas con varios <source>.
  • Olvidar controls: sin él, el audio/vídeo existe en la página pero no hay manera de reproducirlo (a menos que controles con JavaScript).
  • autoplay sin muted: los navegadores bloquean el autoplay con sonido. Si usas autoplay, combínalo con muted.
  • Enlazar recursos de otras webs: funciona, pero depende de que esa web siga viva y permite rastreo de tu actividad. En este curso usamos recursos locales.

Ejercicios

  1. Fácil — reproducir el tono: crea mi-audio.html con un audio que reproduzca ../media/tono-ejemplo.wav y controles. Ábrelo y pulsa play: debe sonar un tono.
  2. Medio — póster y controles: crea mi-video.html con un video de 320 de ancho, con controles, póster ../images/imagen-ejemplo.svg y el subtítulo ../media/subtitulos-ejemplo.vtt asociado.
  3. Difícil — plantilla preparada: escribe el código completo de un reproductor de vídeo con dos fuentes alternativas (mp4 y webm), subtítulos en español y mensaje alternativo para navegadores antiguos. Las rutas pueden ser hipotéticas; añade un comentario que recuerde qué archivos deberías crear para que funcione.

Soluciones razonadas

Intenta los ejercicios antes de leer esto.

Ejercicio 1

<audio controls src="../media/tono-ejemplo.wav">
    Tu navegador no soporta el elemento &lt;audio&gt;.
</audio>

La ruta sube un nivel con ../ porque el archivo está en media/ y nuestra página en html/.

Ejercicio 2

<video controls width="320"
       poster="../images/imagen-ejemplo.svg">
    <track kind="subtitles" src="../media/subtitulos-ejemplo.vtt"
           srclang="es" label="Español">
    Tu navegador no soporta el elemento &lt;video&gt;.
</video>

Ejercicio 3

<video controls width="320">
    <source src="mi-pelicula.mp4" type="video/mp4">
    <source src="mi-pelicula.webm" type="video/webm">
    <track kind="subtitles" src="mi-pelicula.es.vtt"
           srclang="es" label="Español">
    Tu navegador no soporta el elemento &lt;video&gt;.
</video>

Resumen y autoevaluación

El audio se inserta con <audio>, el vídeo con <video>; ambos con controls. Los <source> ofrecen formatos alternativos y <track> añade subtítulos desde un archivo WebVTT. Los recursos deben existir y usar rutas relativas correctas; este curso usa solo archivos locales.
