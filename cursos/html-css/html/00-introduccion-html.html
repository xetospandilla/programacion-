Lección 00: Introducción a HTML

El primer paso: entender qué es HTML y cómo se escribe la estructura de una página web.

Objetivos de esta lección

  • Explicar qué es HTML y para qué sirve.
  • Escribir la estructura mínima de un documento HTML.
  • Distinguir etiqueta, elemento y atributo.
  • Entender cómo se anidan los elementos (el "árbol" de la página).
  • Diferenciar el papel de HTML, CSS y JavaScript.

Conocimientos previos

Ninguno. Esta es la primera lección del bloque HTML. Solo necesitas saber abrir un archivo en tu navegador (doble clic) y editar un archivo de texto (Bloc de notas, VS Code o cualquier editor).

1. ¿Qué es HTML?

HTML son las siglas de HyperText Markup Language (Lenguaje de Marcado de Hipertexto). Es el lenguaje que describe qué contenido hay en una página web: títulos, párrafos, listas, imágenes, enlaces, tablas...

Los navegadores (Chrome, Firefox, Edge...) leen un archivo HTML y lo convierten en la página que ves. HTML no se ejecuta como un programa: es un documento que se interpreta y se pinta.

Puedes ver el HTML de cualquier página con el menú del navegador: normalmente "Ver código fuente" o la tecla Ctrl+U.

2. Estructura mínima de un documento

Todo documento HTML serio empieza con estas líneas:

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Título de la página</title>
</head>
<body>
    <h1>¡Hola, mundo!</h1>
    <p>Este es mi primer documento HTML.</p>
</body>
</html>

Pieza a pieza:

  • <!DOCTYPE html>: le dice al navegador que está leyendo HTML moderno (la versión 5). Va siempre primero.
  • <html lang="es">: la raíz del documento. El atributo lang="es" indica que el contenido está en español; lo usan los lectores de pantalla y los buscadores.
  • <head>: la "cabecera" invisible. Aquí viven los metadatos (información sobre la página), no el contenido visible.
  • <meta charset="UTF-8">: define la codificación de caracteres. Sin él, las tildes y la letra ñ pueden verse mal.
  • <meta name="viewport" ...>: ayuda a que la página se vea bien en pantallas pequeñas (móviles).
  • <title>: el texto que aparece en la pestaña del navegador.
  • <body>: el "cuerpo" visible. Todo lo que se ve en la página va aquí.

Verás el resultado en el navegador: un título grande y un párrafo.

3. Etiquetas, elementos y atributos

Estos tres términos se confunden; conviene separarlos:

  • Etiqueta: el texto entre < y >, por ejemplo <p>. Casi siempre hay dos: apertura y cierre (</p> con barra).
  • Elemento: la etiqueta de apertura + su contenido + la etiqueta de cierre. Es decir, la "pieza" completa.
  • Atributo: información extra que se escribe dentro de la etiqueta de apertura, con forma nombre="valor". Por ejemplo: <a href="https://nodejs.org">Enlace</a> tiene el atributo href con la dirección.
<!-- Un elemento con tres atributos: -->
<img src="../images/imagen-ejemplo.svg" alt="Descripción" width="200">

Las etiquetas sin cierre (como <img> o <br>) se llaman vacías: no envuelven contenido.

4. Anidamiento: la página es un árbol

Los elementos se colocan dentro de otros. Al anidar se forma un "árbol" con un padre y varios hijos.

<ul>
    <li>Primer punto</li>
    <li>Segundo punto</li>
</ul>

Aquí <ul> es el padre y los dos <li> son sus hijos. Regla de oro para no romper nada: lo que se abre se cierra, y se cierra en orden inverso.

Error típico: olvidar la barra de cierre o cruzar las etiquetas. ¿Ves el problema aquí?

<p>Texto <strong>importante</p></strong>

El <strong> se abre dentro del <p>, así que debe cerrarse antes que él: <p>Texto <strong>importante</strong></p>.

5. HTML, CSS y JavaScript: cada uno su papel

  • HTML = la estructura y el contenido (qué hay: un título, un párrafo, una lista...).
  • CSS = la presentación (cómo se ve: colores, tamaños, márgenes...).
  • JavaScript = el comportamiento (qué hace la página al interactuar: abrir un menú, validar un formulario...).

Es una comparación clásica: HTML es el esqueleto, CSS la ropa y JavaScript los músculos. Una página puede funcionar solo con HTML; sin CSS se ve "en bruto" y sin JavaScript no reacciona, pero la estructura siempre la pone HTML.

Errores frecuentes y cómo corregirlos

  • Tildes o ñ que se ven raras: falta <meta charset="UTF-8">. Añádelo en el <head>.
  • Todo el texto sale seguido (sin párrafos): falta envolver el contenido en etiquetas como <p>. Los saltos de línea del editor no cuentan en el navegador.
  • La etiqueta no hace nada: quizá olvidaste la barra en el cierre (</p>, no <p>) o escribiste mal el nombre.
  • Ver el HTML "tal cual" en pantalla: si el navegador muestra <p> como texto, es que algo lo está interpretando mal (por ejemplo, dentro de un comentario o con el carácter < escapado dos veces).

Ejercicios

Trabaja sobre un archivo mi-primera-pagina.html nuevo.

  1. Fácil — estructura mínima: copia el documento del apartado 2 y añade un segundo párrafo y una lista con dos elementos. Ábrelo en el navegador.
  2. Medio — etiquetas y atributos: añade un enlace con el atributo href a esta misma lección (archivo 00-introduccion-html.html) y una imagen cuyo src apunte a ../images/imagen-ejemplo.svg con un alt descriptivo.
  3. Difícil — anidar con orden: escribe el siguiente contenido bien anidado: un <p> que contenga una palabra en <strong> y dentro de la misma palabra una parte en <em>.

Soluciones razonadas

Procura intentar los ejercicios antes de leer esto.

Ejercicio 1

<p>Este es mi primer documento HTML.</p>
<p>Ya tengo un segundo párrafo.</p>
<ul>
    <li>Primer elemento de la lista</li>
    <li>Segundo elemento de la lista</li>
</ul>

Los dos <p> son hermanos (no anidados) y la lista va después. Todo dentro del <body>.

Ejercicio 2

<a href="00-introduccion-html.html">Ir a la introducción</a>
<img src="../images/imagen-ejemplo.svg"
     alt="Paisaje ilustrado de montañas con un sol y un río">

El enlace usa una ruta relativa: como tu página estará en la carpeta html/ (a la par de 00-introduccion-html.html), basta el nombre del archivo. La imagen está una carpeta más arriba, por eso sube con ../.

Ejercicio 3

<p>Una <strong>palabra <em>importante</em></strong> en el texto.</p>

El orden de cierre es inverso al de apertura: se abre strong, luego em, y se cierra em antes que strong.

Resumen y autoevaluación

HTML describe el contenido de una página con etiquetas que se anidan formando un árbol. La estructura mínima incluye <!DOCTYPE html>, <html>, <head> (metadatos) y <body> (contenido visible). Los atributos añaden información a las etiquetas. CSS pinta y JavaScript da comportamiento; HTML pone la base.
