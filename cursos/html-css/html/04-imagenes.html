Página con una imagen


Ejercicios

  1. Crea mi-imagen.html y muestra una imagen con <img> usando una ruta relativa.
  2. Escribe un alt que describa lo que se ve (no el nombre del archivo) y comprueba qué aparece si borras la imagen: ese texto debe seguir explicando el contenido.
  3. Añade un title distinto del alt y observa el texto emergente al pasar el ratón por encima.
