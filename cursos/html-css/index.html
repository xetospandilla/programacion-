Proyectos integradores

Cuatro proyectos completos, progresivos y sin servidor: se abren con doble clic en su index.html. El 04 además incluye JavaScript (recomendado después de las lecciones 43-44 del curso de JS).

  • 01 - Página personal — estructura semántica, anclas, imagen local y variables (requisitos: HTML 0-10; CSS 11, 22, 24).
  • 02 - Landing responsive — presentación de producto ficticio, tarjetas Flexbox y diseño mobile-first (requisitos: CSS 18-22).
  • 03 - Portfolio con Grid — cuadrícula de proyectos con Grid y formulario accesible (requisitos: CSS 18-21 y formularios).
  • 04 - App de tareas — HTML + CSS + JavaScript: lista de tareas con DOM y eventos (requisitos: CSS completo; JS 43-44).

Cada proyecto incluye su README.md con objetivos, mejoras propuestas y una lista de comprobación manual.

Estado del curso

Terminado: lecciones de HTML (0-10), lecciones de CSS (11-25) y los cuatro proyectos integradores. Auditoría final: realizada (tanda 9), sin incidencias abiertas. Inventario en cursos/INVENTARIO.md.

Cómo navegar este curso

La ruta recomendada es seguir los números en orden (00, 01, 02...). Cada lección nueva enlaza a la anterior y a la siguiente, y todas tienen un enlace «Página de Inicio» para volver aquí.
